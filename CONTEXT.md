# Cover Studio

A free, client-side tool that turns app screenshots into a ready-to-publish showcase image. This glossary covers the product itself and the public site that brings people to it.

## Language

### Product

**Cover**:
The image Cover Studio produces: the user's screenshots placed in device frames, with texts, on a background derived from one brand colour.
_Avoid_: Mockup, banner, visual, showcase image (these are search terms, not product terms)

**Template**:
A fixed layout a Cover is drawn with.
_Avoid_: Theme, design, model

**Export format**:
A named pixel size a Cover can be downloaded at (Cover, Open Graph, GitHub, X, Product Hunt, Square).
_Avoid_: Ratio, preset, size

### Public site

**Landing**:
The home page of one locale, presenting the whole product.
_Avoid_: Home, homepage

**Destination**:
A place where a Cover gets published (a README, a GitHub social preview, a Product Hunt gallery…). Each Destination recommends one Export format; several Destinations may share the same one.
_Avoid_: Platform, channel, use case

**Use-case page**:
An indexable page dedicated to one Destination, from which the user can start a Cover with the recommended Export format preselected.
_Avoid_: Landing page, SEO page

**Feature page**:
An indexable page dedicated to one product capability people search for on its own (capturing a website from its address), rather than to a Destination.
_Avoid_: Use-case page (a Feature page is about how the Cover is made, not where it goes)

**Comparison page**:
An indexable page setting Cover Studio side by side with one named alternative tool, on factual differences only.
_Avoid_: Versus page, competitor page

**Guide**:
An indexable editorial page answering an informational question, attached to the one page it supports (a Use-case page, a Feature page or the Landing).
_Avoid_: Article, blog post

**Persona**:
A type of person the public site is written for: the maker launching a product, the open-source maintainer, and (secondary) the developer building a portfolio.
_Avoid_: Target, user (a User is anyone using the editor)
